STEP 05 / 계산법 안내

📘 계산 공식과 해석 방법

아래 항목을 누르면 실제 계산식과 역산 방법을 확인할 수 있습니다. 모든 시간은 계산할 때 초 단위로 처리하고 표시할 때 반올림합니다.

① 통합 계산 · 기본 비교 기준

정방향 계산
통합 풀 예상시간 = (감독님 방식 풀 예상시간 + VDOT 방식 풀 예상시간) ÷ 2

이번 앱의 역산
입력한 목표 풀코스 시간과 위 평균이 같아지도록 5km·10km·하프 기록을 수치적으로 찾습니다.

즉, (F감독님(t) + FVDOT(t)) / 2 = 목표 풀 시간인 t를 구합니다. 각 모델의 역산 기록을 단순 평균한 값은 아닙니다. 리겔은 통합 계산에 포함되지 않습니다.

두 모델에 50%씩 가중치를 준 사용자 정의 기준이며, 검증된 최적 가중치는 아닙니다.

② 리겔(Riegel) · 거리 비율 공식

T₂ = T₁ × (D₂ / D₁)1.06

T₁: 기준 거리 기록 · D₁: 기준 거리 · T₂: 환산 기록 · D₂: 환산 거리

이번 앱은 T₁=목표 풀 기록, D₁=42.195km로 두고 5km·10km·하프를 계산합니다. 지수는 1.06이며 1÷1.06이 아닙니다.

1.06은 대표적인 경험 지수이며 모든 선수에게 정확하게 들어맞지는 않습니다. 특히 1km와 풀코스 간 환산은 신뢰도가 낮아 표시하지 않습니다.

③ VDOT · 잭 다니엘스 경기력 환산

속도 v = 거리(m) ÷ 시간(분)

VO₂ = −4.60 + 0.182258v + 0.000104v²

VDOT = VO₂ / [0.8 + 0.1894393e−0.012778t + 0.2989558e−0.1932605t]

여기서 t는 시간(분)입니다. 목표 풀코스에서 구한 VDOT와 동일한 VDOT를 갖는 각 거리 기록을 반복 계산으로 찾습니다.

동등 경기력의 수학적 추정이며 개인의 장거리 적응, 훈련량, 기온 등은 별도로 반영하지 않습니다. 1km는 계산 범위에서 제외합니다.

④ 감독님 공식 · 마스터즈 경험식

10km = 2 × 5km + 1분 30초

하프 = 2 × 10km + 가산시간
10km 40분 이하: +8분
40분 초과~50분: +9분
50분 초과: +10분

풀 = 2 × 하프 + 남성 13분 / 여성 10분

목표 풀 기록에서 하프 → 10km → 5km 순으로 역산합니다. 10km 경계에서 가산시간이 바뀌므로 일부 목표 기록에는 정확한 역산 해가 없을 수 있어 ‘—’로 표시합니다.

이 공식은 개인 경험을 반영한 모델로, 남녀별 가산시간이 보편적인 생리학적 차이를 증명하는 것은 아닙니다.

⑤ 기록 차이와 마일리지 해석

기록 차이 = 내 현재 기록 − 통합 목표 기록
양수는 목표보다 느림, 음수는 목표보다 빠름을 뜻합니다.

월 마일리지·훈련 횟수·장거리 훈련은 실제 완주 준비도를 설명하는 참고 정보입니다. 이론적 동등 기록에 도달해도 풀코스 목표 달성이 보장되지는 않습니다.

나이와 성별은 VDOT·리겔 결과에 임의 보정하지 않습니다. 성별은 감독님 경험식에만 반영됩니다. 나이·경력은 현재 버전에서 참고 입력값이며 직접적인 기록 보정에 쓰지 않습니다.

📌 핵심: 통합 = 감독님 + VDOT의 정방향 예측 평균을 역산 / 리겔 = 거리 비율의 1.06제곱 / VDOT = 동일 경기력 점수 / 감독님 = 경험식. 이론적 가능성과 실제 마라톤 준비도는 구분해서 보세요.
